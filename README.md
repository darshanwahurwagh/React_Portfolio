# React JS Portfoli
A modern and fully responsive personal portfolio website built using React JS, designed to showcase professional profile, technical skills, projects, education, and contact information in a clean and interactive user interface.

## Features
- #### Home Section  
  Professional landing page with introduction, profile overview, profile image, and two action buttons.

- #### About Section  
  Detailed information about background, career goals, technical expertise, and professional journey.

- # Skills Section  
  Showcase of technical skills, tools, frameworks, and technologies including frontend and backend development.

- # Projects Section  
  Display of featured projects with descriptions, technologies used, and live/demo links.

- # Education Section  
  Academic qualifications, certifications, and educational background.

- # Contact Section  
  Responsive contact form for direct communication along with social media and professional profile links.

## Technologies Used
- React JS
- JavaScript (ES6+)
- HTML5
- CSS3 / Tailwind CSS
- Framer Motion
- React Icons
